# Variables in Go

In Go, variables are explicitly declared and used by the compiler to check type-correctness of function calls.

## Declaring Variables

There are multiple ways to declare variables in Go. Let's explore the differences.

### The `var` Keyword
The standard way to declare a variable is using the `var` keyword. You can declare it with or without an initial value.

```go
var name string = "John Doe"
var age int = 30
